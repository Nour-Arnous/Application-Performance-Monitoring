📖 Step‑by‑Step User Guide
  1. Download the agent file from the button on the left.
  2. For non‑technical users (GUI): Double‑click the file, enter your API Key and Application ID, set the interval, then click Start Monitoring.
  3. For developers (CLI): Open Terminal/CMD and run: APM_Agent.exe --key YOUR_API_KEY --app-id YOUR_APP_ID --interval 5
  4. Verify: Open the Dashboard to see your real‑time data updating automatically!

Your settings are saved automatically in agent_config.ini next to the executable for convenience.
